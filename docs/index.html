Utstationerade per adress

Cirklarnas yta motsvarar antalet utstationerade vid valt datum. Klicka på en cirkel för arbetsgivare och antal. Alla cirklar är lila. Streckad kant markerar ungefärliga gatupositioner. Positioner kan vara osäkra även när en punkt finns. Alla adresser finns i tabellen, även de som saknar kartposition.

Största adresserna

Klicka på en adress för att zooma dit på kartan och visa dess tidsserie. Adresser utan koordinat kan inte zoomas in.

Utveckling per adress

Välj en adress ovan; annars visas de största adresserna vid senaste tillgängliga datum.

Adresser utan geokodning

Samtliga adresser i tillgängliga historiska observationer som saknar koordinater. Du kan använda listan för att rätta adressuppgifter i källdata eller koordinatfilen.
